# MySchedule

A personal scheduling app for iPhone. Two kinds of note feed one unified
schedule. It installs to your Home Screen from Safari, runs offline, and keeps
everything on the phone: no account, no server, nothing uploaded.

The app lives in `docs/` and is served with GitHub Pages
(Settings → Pages → Deploy from a branch → `main` → `/docs`).

Open the site in **Safari**, tap Share, then **Add to Home Screen**.
